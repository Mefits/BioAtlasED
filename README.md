# BioAtlas

**BioAtlas** is a Windows desktop companion for exploration and exobiology in **Elite Dangerous**. It brings the atlas, expedition routing, journey HUD and supporting tools into one window.

## Features

- **Atlas:** explore candidate regions and filter potential exobiology targets.
- **Expedition:** plan a route through candidate systems, inspect planets and follow your next target.
- **Preparation:** plan Fleet Carrier and neutron-star routes (external routing services may be required).
- **Engineering & Materials:** browse engineers, unlock paths and materials.
- **Inventory:** review exobiology samples and recorded sales.
- **HUD / journal integration:** use the Elite Dangerous journal to track your current system and route progress.

## Download

Windows x64 builds are distributed through [GitHub Releases](https://github.com/Mefits/BioAtlasED/releases).

For version **v0.5.6**, download the Windows ZIP, extract the entire `BioAtlas-Qt` folder and run `БиоАтлас Qt.exe`. Keep `app` and `runtime` alongside the executable.

The latest prepared build restores the original Stratum Tectonicas filters; the experimental expanded search is not included. Its F11 / Next behavior waits for confirmation of arrival from the game journal before allowing the next waypoint.

## Setup

1. Extract the entire Windows archive to a local folder.
2. Start `БиоАтлас Qt.exe`.
3. If needed, select the Elite Dangerous journal directory in **Settings**.
4. Back up your application data before replacing an earlier version.

## Status

Early public release. The archive has been checked for integrity, but full Windows integration testing has not been completed. Please report reproducible problems in [Issues](https://github.com/Mefits/BioAtlasED/issues).
